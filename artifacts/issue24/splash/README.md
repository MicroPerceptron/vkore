# Native launch animation checkpoints

Release raster captures at 0, 950, 1500, 2100 and 2300 ms, with 1x and 2x
scale. The logical viewport is 960×720; physical sizes are 960×720 and
1920×1440. Inspect the mark, plate flicker, wordmark alignment and fade.
The post-animation screen uses synthetic fixture content and model labels.
These fixed-time render checkpoints supplement actual native app operation;
they do not establish runtime readiness or measure frame-to-frame cadence.

Generated by the existing ignored `capture_and_benchmark_ui` test with
`VKORE_UI_CAPTURE_FAST=1`, `VKORE_UI_SCALE`, `VKORE_UI_WIDTH`,
`VKORE_UI_HEIGHT`, `VKORE_UI_SPLASH`, and `VKORE_UI_CAPTURE`.
See [validation](../../../docs/issue24-validation.md).
